# One Week

A five-day career simulation. Try a profession for one honest week before you choose the path.

**Play here:** https://agency-r.github.io/career-week/

Open the link in a modern browser (Chrome recommended). The game is a single HTML file and loads three.js from a CDN, so an internet connection is required.

Supported careers: Software Engineer, Registered Nurse, High-School Teacher, Graphic / Product Designer, Marketing Manager, Electrician, Chef / Kitchen Lead, and Architect.
